# 产品改进：先做能当天落地的小步

竞品调研见 [调研结论](../research/product-benchmark-2026-10-15/README.md)。当前按小切片改真实页面，不先建设完整任务、版本和验收系统。

## 已落地

Teamspace 的会话、Agent 配置、记忆和工作区页面现在共享页面导航，能直接看见页面名称和当前位置。会话链接保留当前会话 ID。实现使用既有 Element Plus 按钮、Cordis 路由和共享主题，涉及 `client/navigation.ts` 与共享 `im.css`。

## 下一小步

每次只挑一个当前页面的高频问题，优先处理用户最近实际遇到且能复现的问题。改动要能在当前界面直接看到，避免新增一整套业务对象或单独的演示产品。完整竞品建议留作后续参考，不作为当天改造清单。
