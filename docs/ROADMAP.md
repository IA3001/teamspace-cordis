## M1　最基础的插件 + 调试控制台

### 需求原文（用户指示，2026-09-27）

> 然后,接下来是开发最基础的插件组件了，比如，插件系统查看插件，日志系统插件，数据库系统插件，这个插件极其的基础，
> 必须要求，我可以在后端的 web 控制台美观的看到这些页面（调试用）（初步设计不需要登录验证，直达的，建议放在5172端口）

### 要什么

| # | 交付物 | 说明 |
|---|---|---|
| 1 | 插件查看插件 | web 控制台里能看到「当前装了哪些插件、各自什么状态」，数据来自 `ctx.loader` 的运行时清单，**不是写死的假数据** |
| 2 | 日志系统插件 | 统一的日志插件 + 能在 web 控制台里**美观**地看日志 |
| 3 | 数据库系统插件 | 统一的数据库插件（连接 / 迁移 / 种子沿用既有惯例） |
| 4 | web 调试控制台 | 承载上面三个页面，端口 **5172**，**无登录、直达** |

### 硬性要求

- **美观**——不是「能看就行」。必须走统一 UI 组件库、主题一致，见**铁律 1**
- **无登录、直达**——初期不做鉴权，浏览器打开 5172 直接进
  （原文「初步设计不需要登录验证」，即**后续会加**，不是永久不要）
- **开发态由 Vite 提供在 5172，生产态由后端同源提供**——沿用同类工程既有做法

### 前置门槛：不满足则 M1 禁止开工

> 用户原话：**以上的内容必须是根本的前提，如果上方的内容无法做的完美，不符合我的预期，就禁止下面的事情进行**

- [ ] 铁律 1 的**组件库选型已定**，并写进 `.rules/IRON-RULES.md` 的选型表
- [ ] 设计令牌（颜色 / 间距 / 圆角 / 字号）的出处已定
- [ ] 样式门禁断言已建，且**故意改坏一次确认它真的会红**

### 验收标准

- [ ] 浏览器打开 `http://localhost:5172` 直接看到控制台，**无需登录**
- [ ] 插件 / 日志 / 数据库三个页面都能看到**真实运行时数据**
- [ ] 三个页面的样式里**没有**内联样式、自写样式块、硬编码颜色
- [ ] 端口 5172 来自 `.env`，代码里找不出第二个写死它的地方
- [ ] 新增行为都有**会红的**断言

### 端口

唯一出处是 `.env`：`DEBUG_PORT=5172`。

口径：后端 `8080` / **调试控制台 `5172`（M1 新开，测试用）** / 控制台 `5173` / 团队空间 `5174`。

> ⚠ 5172 是**新开**的测试端口，与既有的正式控制台 `5173` **并存**，不是替换它。别把两个搞混。
