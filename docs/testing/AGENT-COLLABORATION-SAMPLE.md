# 多人会话 Agent 协作验收样例

人类成员：111（发起人）、123（独立验收者）。Agent：需求分析师、编码者、测试者、会议记录官。创建专用测试会议，不在正式会议中测试。按下面顺序逐条发送，等目标 Agent 有真实答复后再发下一条；绿色后台扫描状态不等于任务成功。

## 1. 需求与记忆（111 发送）

```text
@需求分析师 本轮做一个独立验收小项目“优惠计算协作验收”。请确认并记住这些已批准规则：唯一需求标识 COLLAB-DISCOUNT-20261014；金额全部使用整数分；discountedTotal(items, discountPercent) 接收非负安全整数数组和 0～100 的整数折扣百分比；先求和，再乘 (100-discountPercent)/100，向下取整；不允许修改输入；非法数组、金额、折扣或合计溢出抛 RangeError。示例：[199,201]、25 应返回 300；[101]、50 应返回 50；空数组返回 0。本轮仅处理这个小项目，不需要外部系统、业务部署或额外负责人审批。请简要复述规则，列出可执行验收项；未实际保存长期记忆时不要宣称已保存。
```

## 2. 第二位成员验收需求（123 发送）

```text
@需求分析师 我是独立验收者 123。请仅从可访问的会话或记忆中复述本轮唯一需求标识、金额单位和取整规则。新增验收：100% 折扣返回 0；输入含负数、小数、NaN 或 Infinity 时必须抛 RangeError。请说明引用的是会话记录还是长期记忆，不要混淆。
```

## 3. 编码并交接（111 发送）

```text
@编码者 按本轮已确认的“优惠计算协作验收”需求实现 discountedTotal(items, discountPercent)。使用 JavaScript ES module，无外部依赖。通过真实工作区写入工具保存到 projects/collab-discount/src/discount.mjs，并执行最小自测。最终答复必须包含：完整实际保存的源码、文件路径、实际调用的工具和自测结果。各 Agent 个人工作区隔离，测试者不能直接读取你的私有文件，所以必须在这条回复中交接完整源码；不要只报路径或口头说已完成。
```

## 4. 独立测试（123 发送）

```text
@测试者 请测试编码者在本会话最新交接的完整 discountedTotal 源码，不要自行实现替代版本，也不要假定可读编码者个人工作区。把收到的原始实现原样放入你的隔离 Node.js 执行脚本，用 node:assert/strict 实际执行至少这些断言：[199,201],25=>300；[101],50=>50；[],0=>0；[1],100=>0；[0],0=>0；不修改输入；负数/小数/NaN/Infinity 金额抛 RangeError；非数组抛 RangeError；-1/101/1.5 折扣抛 RangeError；总和超过安全整数抛 RangeError。额外运行负向对照：将向下取整改为向上取整，用 [101],50 的断言证明测试会失败。请分别报告原始实现通过/失败数、命令或工具、真实输出，以及错误版本确实被检出。没有调用执行工具或无法取得原始源码时，明确报告阻塞，不得声称通过。
```

## 5. 有缺陷时修复（111 发送）

```text
@编码者 根据测试者真实失败报告修复原实现，更新原文件并交接修复后的完整源码，列出具体修改。若全部通过，则明确无需修复，不制造新改动。
```

若修改了代码，重新发送第 4 步。旧测试结果不能证明新版本通过。

## 6. 反馈与可追溯总结（111 发送）

```text
@会议记录官 请汇总本轮需求标识、两位人类成员的参与、需求规则、编码交付路径、测试实际工具与结果、负向对照、发现的缺陷和修复。每项标为“有记录证实/尚未证实/失败”，关联实际会话消息。只有确实看到测试执行成功的记录才能写通过；后台已扫描、模型自称完成、截图上的绿色状态都不能代替测试证据。不要输出隐藏思维链，只总结已记录的决定、依据、操作和结果。
```

## 验收边界

- 同时打开两个独立浏览器会话分别登录 111 / 123，确认互相看到实时消息；代填或邀请不等于第二人真实操作。
- 工作区可以查看最近处理原消息、处理结果和工具调用；刷新后记录仍然存在。
- 长期记忆须在“记忆库”查看实际保存的相关条目；当前会话复述正确只证明上下文读取成功。若要验证跨会话记忆，在新会议邀请同一 Agent，仅提供唯一需求标识，问金额单位和取整规则，并核对引用来源。
- 若出现“待负责人决策”，检查实际决策权限及入口，不把暂停误认为模型超时。
- 隔离执行工具不可用、模型请求超时、代码交接缺失或多用户访问失败，均记录为失败或阻塞。禁止以模拟输出冒充真实成功。
